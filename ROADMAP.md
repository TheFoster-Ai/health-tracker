# Health Tracker Roadmap

## Done
- [x] Food database: search (USDA + Open Food Facts), barcode scanning, serving sizes, recent and favorite foods
- [x] Dark, modern redesign (progress rings, per-metric colors, new app icon)
- [x] Detailed workout logging (exercises, sets, reps, weight)
- [x] Personal records (trophy screen)
- [x] Current stats (1RM reference)
- [x] Saved recipes (build from search/scan/manual, log by serving or gram, save from log)
- [x] Per-exercise notes with up/down tags
- [x] Workout autosave / crash-proof drafts
- [x] Edit any logged entry (food, water, sleep, weight) + auto calories from macros
- [x] Weight tracking with trends (7-day average chart, goal + estimate)

## Up next
- [ ] Meal ordering: turn recipes into a grocery list and a saved standard order you can send to a store like Walmart for pickup
- [ ] Smart reminders that learn your habits (e.g. if breakfast is usually logged by 8:30, remind you when it isn't) - needs push notifications
- [ ] Charts and weekly insights (weight, average sleep, calories vs. goal)
- [ ] Goals and personalized targets (calorie and macro budget from weight, height, activity, and goal)
- [ ] Reminders (water, meals, weigh-ins)
- [ ] Streaks and progress milestones
- [ ] Accounts and cloud sync (survive a lost phone, work across devices)
- [ ] Apple Health sync (steps, workouts, sleep, weight) - needs a real App Store app
- [ ] Move to a real App Store app (Apple Developer account, $99/yr)
- [ ] Small server to hide the USDA key and raise search limits as users grow
- [ ] Lift tutorials: how-to guides for each exercise (form cues, common mistakes, video/animation), reachable from the exercise picker and workout editor
